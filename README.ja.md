# mof_svg_char

SVGとバニラJavaScriptで作成された、かわいいもふもふキャラクターのアニメーションです。外部ライブラリを使用せず、ブラウザ上で動的にアニメーションを生成します。

## デモ

ライブデモはこちら: **[https://code4fukui.github.io/mof_svg_char/](https://code4fukui.github.io/mof_svg_char/)**

## 特徴

アニメーションはフレームごとにプロシージャル生成され、以下の動的なエフェクトを備えています：

- **浮遊モーション:** キャラクターがゆったりと上下に浮遊します（±15px）。
- **スクイーズアニメーション:** わずかな「潰れと伸び（squish and stretch）」のエフェクトがかかります（±10%のスケール変化）。
- **まばたき:** 15フレーム周期で定期的にまばたきをします。
- **もふもふの波打ち:** 外側の「もふもふ」の円が脈打つように波打ちます（±3pxの半径変化）。
- **キラキラパーティクル:** 不透明度がアニメーションする5つの装飾用パーティクルが、キャラクターの周囲を回ります。

## 使い方

モダンなWebブラウザで `index.html` を開くだけで実行できます。アニメーションは `<svg>` 要素内にレンダリングされ、`setInterval` を使用して50ミリ秒ごとに更新されます。
